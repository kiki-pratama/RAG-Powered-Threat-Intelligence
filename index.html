AI Investigation

Investigation Summary

Incident Details

Trigger: Windows Security Event ID 4738 (User Account Changed).

Hostname: DBZNEWPROCDC1 (Domain Controller).

Event: A user account was modified to enable the 'Password Never Expires' flag.

Impact

This configuration change allows a compromised account to bypass organizational password rotation policies, providing an attacker with a stable, persistent foothold in the environment that is difficult to detect through standard password-related alerts.

Recommended Response Actions

  • Identify the administrative account or process that performed the modification.
  • Review recent activity associated with the modified user account to identify potential unauthorized use.
  • Verify if the change was part of an authorized service account maintenance window.
  • If unauthorized, immediately disable the 'Password Never Expires' attribute, reset the user's password, and audit for secondary persistence mechanisms.

Response Playbook

PERSISTENCE

This playbook provides steps to identify and remediate unauthorized account modifications in Active Directory that promote long-term persistent access.

Detect

HIGH PRIORITY
  1. Validate the Event ID 4738 source and verify it originated from a Domain Controller.
  2. Check the 'SubjectUserName' field to identify which account performed the modification.

Investigate

HIGH PRIORITY
  1. Check the modified account's recent login history for unusual source IPs or login times.
  2. Review logs for other administrative changes made by the user who performed this modification around the same time.

Contain

IMMEDIATE PRIORITY
  1. Disable the account if unauthorized activity is suspected.
  2. Force a password reset for the modified account.
  3. Revoke active sessions/tickets for the account (e.g., Kerberos TGT reset).

Eradicate

MEDIUM PRIORITY
  1. Remove the 'Password Never Expires' flag via Active Directory Users and Computers or PowerShell.
  2. Remove any unauthorized tools or persistence artifacts detected on the host.

Recover

LOW PRIORITY
  1. Monitor the account for re-occurring unauthorized modifications.
  2. Review and update AD auditing policies to alert on account attribute changes in real-time.
